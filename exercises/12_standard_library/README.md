# 12_standard_library

Work through these files in order.

- [Permission flags with bit masks](01_flags.py) — IntFlag, enums, bitwise operators
- [Encode a binary record](02_binary_records.py) — struct, bytes, endianness, hashlib
- [Parse structured log lines](03_regex.py) — re, named groups, fullmatch
- [Compare timezone-aware timestamps](04_datetime.py) — datetime, timezone, ISO 8601, timedelta
- [Exact invoice arithmetic](05_decimal.py) — Decimal, quantize, ROUND_HALF_UP, finite values
- [Find exact-size combinations](06_itertools.py) — combinations, itertools, generator expressions
- [Stable priority queue](07_heap.py) — heapq, itertools.count, tuple ordering
- [Reproducible simulation](08_random_statistics.py) — random.Random, statistics, local RNG state
